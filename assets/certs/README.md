# Certificados

Coloque aqui os arquivos dos certificados (PDF ou imagem) baixados localmente.
Cada certificado listado em `assets/js/app.js` (array `CERTS`) tem um campo
`file` apontando para o nome do arquivo dentro desta pasta. Basta salvar o
arquivo baixado com o **mesmo nome** indicado abaixo (mantendo a extensão
`.pdf`, `.jpg` ou `.png` conforme o arquivo que você tiver):

| Certificado                          | Nome de arquivo esperado          |
|---------------------------------------|------------------------------------|
| AWS Technical Essentials              | `aws-technical-essentials.pdf`     |
| Introduction to AWS                   | `introducao-aws.pdf`               |
| FastAPI                               | `fastapi.pdf`                      |
| Prompt Engineering                    | `prompt-engineering.pdf`           |
| Generative AI from Scratch            | `ia-generativa.pdf`                |
| Git & GitHub                          | `git-github.pdf`                   |
| Python (Santander)                    | `python-santander.pdf`             |

Se o arquivo que você tem for uma imagem (ex: `.jpg`/`.png`) em vez de PDF,
troque a extensão tanto no arquivo salvo aqui quanto no campo `file`
correspondente em `assets/js/app.js` (array `CERTS`).

Ao clicar em um certificado no site, o arquivo abre em uma nova aba do
navegador.
